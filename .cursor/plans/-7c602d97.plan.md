## 1. نظام المصادقة (JWT Authentication)

### 1.1 Database Models

- **ملف**: `api/app/models.py`
  - إضافة `User` model مع الحقول: `id`, `username`, `email`, `hashed_password`, `is_active`, `created_at`
  - إضافة `SystemUser` enum/flag للتمييز بين SystemUser والمستخدمين العاديين

### 1.2 Authentication Schemas

- **ملف**: `api/app/schemas.py`
  - `UserCreate`, `UserLogin`, `Token`, `UserResponse` schemas

### 1.3 Authentication Endpoints

- **ملف**: `api/app/main.py`
  - `POST /api/auth/login` - تسجيل الدخول وإرجاع JWT token
  - `GET /api/auth/me` - الحصول على معلومات المستخدم الحالي
  - `POST /api/auth/refresh` - تحديث token

### 1.4 JWT Utilities

- **ملف جديد**: `api/app/auth.py`
  - دوال: `create_access_token()`, `verify_token()`, `get_current_user()`
  - Dependency للتحقق من JWT في protected endpoints

### 1.5 Protect Saved Images Endpoint

- **ملف**: `api/app/main.py`
  - تعديل `GET /api/saved_images` ليتطلب JWT authentication
  - إضافة `Depends(get_current_user)` للتحقق من SystemUser

### 1.6 Environment Variables

- **ملف**: `.env.example`
  - `JWT_SECRET_KEY` - مفتاح التوقيع
  - `JWT_ALGORITHM` - خوارزمية التوقيع (default: HS256)
  - `JWT_EXPIRATION_HOURS` - مدة صلاحية token
  - `SYSTEM_USER_USERNAME` - اسم المستخدم الافتراضي
  - `SYSTEM_USER_PASSWORD` - كلمة المرور الافتراضية
  - `SYSTEM_USER_EMAIL` - البريد الافتراضي

### 1.7 Dependencies

- **ملف**: `api/requirements.txt`
  - إضافة `python-jose[cryptography]` للJWT
  - إضافة `passlib[bcrypt]` لتشفير كلمات المرور

### 1.8 Database Initialization

- **ملف**: `api/app/init_db.py` أو إنشاء `api/app/auth_init.py`
  - إنشاء SystemUser افتراضي عند أول تشغيل إذا لم يكن موجوداً

## 2. نظام البلاغات (Missing Reports System)

### 2.1 Database Models

- **ملف**: `api/app/models.py`
  - إضافة `MissingReport` model:
    - `id`, `report_number` (unique, indexed) - رقم البلاغ الفريد (REP-YYYY-XXXX)
    - `reporter_name`, `reporter_email`, `reporter_phone`
    - `child_name`, `child_photo_path`, `child_compreface_face_id`
    - `status` (enum: open, in_progress, resolved, closed)
    - `created_at`, `updated_at`, `closed_at`
    - `created_by_user_id` (nullable - للبلاغات العامة)
  - إضافة `ReportMatch` model:
    - `id`, `report_id` (FK), `captured_image_id` (FK)
    - `similarity_score`, `camera_id`, `camera_name`
    - `matched_at`, `notified_at` (nullable)
    - `external_api_called` (boolean)

### 2.2 Schemas

- **ملف**: `api/app/schemas.py`
  - `MissingReportCreate` - لإنشاء بلاغ جديد
  - `MissingReportResponse` - للاستجابة
  - `ReportStatusUpdate` - لتحديث الحالة
  - `ReportMatchResponse` - لمعلومات التطابق
  - `ReportTrackRequest` - لتتبع البلاغ (phone + report_number)
  - `ReportTrackResponse` - لنتيجة التتبع

### 2.3 CRUD Operations

- **ملف**: `api/app/crud.py`
  - `create_missing_report()` - إنشاء بلاغ جديد مع توليد رقم فريد
  - `get_missing_report_by_number()` - البحث برقم البلاغ
  - `get_missing_report_by_phone_and_number()` - للتحقق من التتبع
  - `get_open_reports()` - البلاغات المفتوحة فقط
  - `get_in_progress_reports()` - البلاغات قيد المعالجة
  - `get_all_reports()` - جميع البلاغات (لـ SystemUser)
  - `update_report_status()` - تحديث حالة البلاغ
  - `close_report()` - إغلاق البلاغ
  - `create_report_match()` - تسجيل تطابق

### 2.4 Public Endpoints (No Auth Required)

- **ملف**: `api/app/main.py`
  - `POST /api/reports/create` - إنشاء بلاغ جديد
    - التحقق من وجود وجه في الصورة قبل الحفظ
    - توليد رقم البلاغ: `REP-{YYYY}-{XXXX}` (4 أرقام تسلسلية)
  - `POST /api/reports/track` - تتبع حالة البلاغ
    - Body: `phone`, `report_number`
    - إرجاع: حالة البلاغ، التطابقات (إن وجدت)

### 2.5 Protected Endpoints (SystemUser Only)

- **ملف**: `api/app/main.py`
  - `GET /api/admin/reports` - قائمة جميع البلاغات (مع pagination)
  - `GET /api/admin/reports/{report_id}` - تفاصيل بلاغ معين
  - `PUT /api/admin/reports/{report_id}/status` - تحديث حالة البلاغ
  - `GET /api/admin/reports/{report_id}/matches` - التطابقات لبلاغ معين

## 4. مقارنة الصور مع البلاغات (Background Job)

### 4.1 Background Comparison Function

- **ملف**: `api/app/main.py`
  - إضافة `compare_with_reports_background()`:
    - يتم استدعاؤها بعد حفظ الصورة بنجاح في `process_image_background()`
    - البحث في البلاغات بحالة `in_progress` فقط
    - مقارنة الصورة مع `child_compreface_face_id` لكل بلاغ
    - إذا كان التطابق > 0.88:
      - إنشاء `ReportMatch` record
      - استدعاء `notify_external_api()` في background

### 4.2 External API Notification

- **ملف جديد**: `api/app/external_api.py`

      ```json
          "report_number": "...",

            "email": "...",
            "phone": "..."
          },
          "child": {
            "name": "...",
            "photo_url": "..."
          }
        },
        "match": {
          "similarity": 0.92,
          "matched_at": "..."
        },
        "camera": {
          "camera_id": "...",
          "camera_name": "...",
          "timestamp": "...",
          "latitude": ...,
          "longitude": ...,
          "place_name": "...",
          "description": "..."
        },
        "image_url": "..."
      }
      ```

    - تحديث `ReportMatch.notified_at` و `external_api_called=True`

### 4.3 Environment Variables

- **ملف**: `.env.example`
  - `EXTERNAL_API_URL` - URL للـ API الخارجي
